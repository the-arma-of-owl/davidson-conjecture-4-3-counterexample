## 1. Proposition 3 (`Prop3.lean`, `Checker.lean`)

Paper (line 92): "**Proposition 3.** For $K=79$ there is no $\sigma\in[-1,1]^{80}$ with $\tau_j=\sum_{i=0}^{12}a_i\sigma_{i+j}\in3(2\mathbb Z+1)$ for all $0\le j\le 67$."

```lean
theorem Davidson.prop3 : ¬ ∃ σ : Fin 80 → ℝ, (∀ i, |σ i| ≤ 1) ∧
    ∀ j : Fin 68, ∃ m : ℤ,
      ∑ i : Fin 13, (a i : ℝ) * σ ⟨i.val + j.val, by omega⟩ = 3 * (2 * m + 1)
```
The statement matches the paper: it is over ℝ, uses 0-based indices, and covers j = 0..67. Nothing is assumed. The bound |τ_j| ≤ 19, the reduction to T = {±3, ±9, ±15} and the sign symmetry σ ↦ −σ are all proved inside Lean.

Structure:
- `Checker.lean` contains the following.
  - The checker `checkRoot : Cert → Bool`. A `Cert` is a tree of interval nodes carrying the multipliers `yu`/`yl`; every certificate node is of type I. The checker follows `check_proof.py`: it computes affine forms in x = (σ_0..σ_11), uses `σ_{k+12} = (τ_k − c_k)/2`, and computes the bounds `ub = Σ(y_kτ_k + 2|y_k|) + ‖A‖₁ + B` and the corresponding lb. Every τ ∈ T whose slab [τ−2, τ+2] meets [lb, ub] must be a child, with only τ > 0 allowed at the root. Every node must have depth < 68.
  - The soundness theorem, kernel-checked:
    ```lean
    theorem Davidson.prop3_of_check (c : Cert) (hc : checkRoot c = true) : Prop3Statement
    ```
    `Prop3Statement` is definitionally the statement of `prop3`. The theorem holds for **every** tree, so the parser and the converter need not be trusted.
- `CertData.lean`: `certStr := include_str "data/cert_L68.txt"`. This is the published JSONL certificate re-serialised as a preorder token stream by `tools/convert_cert.py`. The multipliers are unchanged.
- `Parse.lean`: an unverified parser, `partial def`.
- `Prop3.lean`: `theorem cert_ok : checkRoot cert = true := by native_decide`, followed by `prop3 := prop3_of_check cert cert_ok`.

**Difference to note:** acceptance of the certificate rests on `native_decide`. In Lean 4.37, `native_decide` no longer uses `Lean.ofReduceBool`; that constant no longer exists. It instead adds a per-use auxiliary axiom:
```
axiom Davidson.cert_ok._native.native_decide.ax_1_1 : decide (Davidson.checkRoot Davidson.cert = true) = true
```
This axiom is justified by compiled evaluation. Here the evaluation goes through the IR interpreter plus the native Lean runtime for Rat/Int/GMP. The trust is the same kind as `Lean.ofReduceBool`: you must trust the Lean compiler and interpreter. Soundness of the checker is fully kernel-checked.

Negative tests are in `Test_Corrupt.lean`; it is not part of the proof. Dropping a required child at preorder nodes 1000, 30000 and 60000 makes the checker return `false`. Negating `yu` at nodes 1001, 30001 and 60001 also gives `false`. The checks are `#guard` commands, so the file fails to compile if any corrupted tree is accepted. A positive control checks that the unmodified tree is accepted.

## 2. Sharpness, K = 78 (`Sharp78.lean`)

Paper (line 114): "`certificate/fB_K78_feasible_cert.json` gives an exact rational σ and a word τ for K=78". Paper (line 20): "the subgraph generated by 1,α,…,α^78 is three-colourable."

```lean
theorem Davidson.K78.sharp78 : ∃ σ : Fin 79 → ℝ, (∀ i, |σ i| ≤ 1) ∧
    ∀ j : Fin 67, ∃ m : ℤ,
      ∑ i : Fin 13, (a i : ℝ) * σ ⟨i.val + j.val, by omega⟩ = 3 * (2 * m + 1)
```
The witness is the published σ_0..σ_11 together with σ_{k+12} = (τ_k − c_k)/2. It is stored as integers N78 over a common denominator D78 (141 digits), generated by `tools/gen_k78.py`. The arithmetic is checked by `decide +kernel`, which is kernel reduction; no `native_decide` is used. Only the finite feasibility statement is formalized. The step "feasible ⇒ G_78 is 3-colourable" (Lemma 2′) is **not** formalized.

## 4. Lemma 2 (necessity) and the main lower bound (`Height.lean`, `Extension.lean`, `Criterion.lean`, `Gamma.lean`)

No `sorry`, `admit`, new `axiom` or `native_decide` in these four files. This section supersedes the "Not formalized" remarks above as far as Lemma 2 (necessity) and the lower bound χ(Γ_α) ≥ 4 are concerned.

### 4.1 Graph Γ_α (`Gamma.lean`)

Paper (line 7; also §1, line 24): "$\Gamma_\alpha=\mathrm{Cay}(\mathbb Z[\alpha],\{\pm\alpha^n : n\ge 0\})$ … two points of $\mathbb Z[\alpha]\subset\mathbb C$ are adjacent when they differ by $\pm\alpha^n$".

```lean
def Davidson.Gamma (α : ℂ) : SimpleGraph (Algebra.adjoin ℤ ({α} : Set ℂ)) where
  Adj z w := z ≠ w ∧ ∃ n : ℕ, (w : ℂ) - z = α ^ n ∨ (z : ℂ) - w = α ^ n
```
ℤ[α] is `Algebra.adjoin ℤ {α}`, the subring of ℂ generated by α (equal to the additive group generated by the powers α^n). The condition `z ≠ w` only removes loops; it is automatic here because α ≠ 0.

### 4.2 Main theorem (lower bound)

Paper (line 116): "**Proof of the Theorem.** By Proposition 3 and Lemma 2, $G_{79}$ is not $3$-colourable, so $\chi(\Gamma_\alpha)\ge\chi(G_{79})\ge4$."

```lean
theorem Davidson.gamma_not_colorable (α : ℂ) (hα : Polynomial.aeval α Poly.f = 0) :
    ¬ (Gamma α).Colorable 3

theorem Davidson.four_le_chromaticNumber (α : ℂ) (hα : Polynomial.aeval α Poly.f = 0) :
    4 ≤ (Gamma α).chromaticNumber
```
Differences:
- α is any complex root of f; nothing else is assumed (|α| = 1 is not needed; α ≠ 0 is derived from `Poly.roots_on_circle`).
- The proof does not go through G_79 or M_79 as separate objects, and does not use Lemma 1. A colouring C of Γ_α is pulled back to the grid by c(v) = C(∑_{i<80} v_i α^i). Grid neighbours map to Γ_α-neighbours, and c is ℓ_j-invariant because ∑_i (ℓ_j)_i α^i = α^j f(α) = 0. Only this direction of Lemma 1 (ℓ_j ∈ ker π) is needed, and it is trivial.
- The upper bound χ(Γ_α) ≤ 4 ([D, Thm 4.1]) is not formalized, so χ(Γ_α) = 4 is not stated.

### 4.3 Lemma 2 (necessity), grid form (`Criterion.lean`)

Paper (line 66): "**Lemma 2 (necessity).** If $G_K$ is properly $3$-colourable, then there are reals $\sigma_0,\dots,\sigma_K\in[-1,1]$ such that $\tau_j:=\sum_{i=0}^{12}a_i\,\sigma_{i+j}\ \in\ 3(2\mathbb Z+1)\qquad(0\le j\le K-12)$." The proof (line 69) works with "$\hat c=c\circ\pi$ on the grid graph $\mathbb Z^{K+1}$ (steps $\pm e_n$)", which is $\ker\pi$-invariant.

```lean
def Davidson.ell (K j : ℕ) : Fin (K + 1) → ℤ := fun i =>
  if h : j ≤ i.val ∧ i.val ≤ j + 12 then a ⟨i.val - j, by omega⟩ else 0

theorem Davidson.lemma2 (K : ℕ) (c : (Fin (K + 1) → ℤ) → ZMod 3)
    (hproper : ∀ v (n : Fin (K + 1)), c (v + Pi.single n 1) ≠ c v)
    (hper : ∀ v (j : Fin (K - 11)), c (v + ell K j) = c v) :
    ∃ σ : Fin (K + 1) → ℝ, (∀ i, |σ i| ≤ 1) ∧
      ∀ j : Fin (K - 11), ∃ m : ℤ,
        ∑ i : Fin 13, (a i : ℝ) * σ ⟨i.val + j.val, by omega⟩ = 3 * (2 * m + 1)
```
`ell K j` is the coefficient vector ℓ_j of x^j f(x) in ℤ^{K+1}; `Fin (K - 11)` is j = 0..K−12.
Differences:
- The hypothesis is about the grid colouring ĉ, not about G_K: ĉ is proper on the grid and invariant under ℓ_0,…,ℓ_{K−12}. This is exactly what the paper's proof uses. Every proper colouring c of G_K gives such a ĉ = c∘π (because ℓ_j ∈ ker π), so the Lean statement implies the paper's; the G_K form itself is not stated separately.
- K is arbitrary; for K < 12 the conclusion is vacuous (`Fin (K - 11)` is empty), so the hypothesis K ≥ 12 is dropped.
- Colours are in `ZMod 3`. In `gamma_not_colorable` a `Coloring (Fin 3)` is used directly (`ZMod 3` is definitionally `Fin 3`).

A more general form, for any finite family of periods, is also proved:
```lean
theorem Davidson.necessity {N J : ℕ} (ℓ : Fin J → Fin N → ℤ) (c : (Fin N → ℤ) → ZMod 3)
    (hproper : ∀ v (n : Fin N), c (v + Pi.single n 1) ≠ c v)
    (hper : ∀ v (j : Fin J), c (v + ℓ j) = c v) :
    ∃ σ : Fin N → ℝ, (∀ i, |σ i| ≤ 1) ∧ ∀ j, ∃ t : ℤ,
      ∑ n, (ℓ j n : ℝ) * σ n = t ∧ (3 : ℤ) ∣ t ∧ t ≡ ∑ n, ℓ j n [ZMOD 2]
```
`lemma2` follows from it via `ell_sum` (∑_i (ℓ_j)_i σ_i = ∑_k a_k σ_{k+j}) and ∑_k a_k = 1 (`sum_a`, by `decide`).

### 4.4 Proof structure (follows the paper's proof of Lemma 2)

- `Height.lean`: the step `step c v n ∈ {±1}` (the lift of c(v+e_n) − c(v)); no winding on unit squares (`step_closed`); a closed step function is a gradient (`potential`, built coordinate by coordinate instead of via the cycle space); the height h (`height_exists`) with h ≡ c (mod 3) (`height_mod3`), h(v+u) − h(v) ≡ ∑u_i (mod 2) (`height_mod2`), |h(v+u) − h(v)| ≤ ‖u‖₁ (`height_lipschitz`), constant increments along periods (`height_period`), and additivity (`shift_comb`).
- `Extension.lean`: `extend` — from |∑ m_j τ_j| ≤ ‖∑ m_j ℓ_j‖₁ for integer m to rational m (common denominator), to real m (density of ℚ^J, `DenseRange.piMap`), then Hahn–Banach (`exists_extension_of_le_sublinear`) with N(x) = ∑|x_i| on span{ℓ_j}. Linear independence of the ℓ_j is not needed: well-definedness follows from the inequality.

## 5. Noninteger roots and the refutation of Conjecture 4.3 (`NonInteger.lean`, `Conjecture.lean`)

No `sorry`, `admit`, new `axiom` or `native_decide` in these two files. This section supersedes the remark in 4.6 and in the README that "α is an algebraic noninteger" is not formalized.

### 5.1 The paper's definitions and the conjecture

Paper §1 (line 24): "Following [D], a *direction parameter* is a unit complex number $\alpha$, and $\Gamma_\alpha=\mathrm{Cay}(\mathbb Z[\alpha],\{\pm\alpha^n : n\ge 0\})$. For algebraic $\alpha$, let $f=\sum_{i=0}^d a_ix^i$ be its primitive integer minimal polynomial with $a_d>0$. Then $\alpha$ is *noninteger* if $a_d\ge2$, i.e. if $\alpha$ is not an algebraic integer."

Paper §1 (line 26): "**[D, Conjecture 4.3].** If $\alpha$ is an algebraic noninteger direction parameter, then $\chi(\Gamma_\alpha)\le 3$."

```lean
def Davidson.Conjecture43 : Prop :=
  ∀ α : ℂ, ‖α‖ = 1 → IsAlgebraic ℚ α → ¬ IsIntegral ℤ α → (Gamma α).chromaticNumber ≤ 3

theorem Davidson.conjecture43_false : ¬ Conjecture43
```
`Gamma α` is the graph of 4.1 (vertex set `Algebra.adjoin ℤ {α}` = ℤ[α] ⊂ ℂ); `chromaticNumber` takes values in `ℕ∞`.
Differences:
- "noninteger" is formalized by its second form, "α is not an algebraic integer" (`¬ IsIntegral ℤ α`), not by "a_d ≥ 2" for the primitive minimal polynomial. The two are equivalent by Gauss's lemma (an algebraic number is an algebraic integer iff its primitive minimal polynomial is monic); this equivalence is not proved in Lean.
- "algebraic" is `IsAlgebraic ℚ α`; "unit complex number" is `‖α‖ = 1`.

### 5.2 Every root of f is a counterexample

Paper §2 (lines 47, 49): "Since $f$ is not monic, no root is an algebraic integer, and in particular no root is a root of unity." "So every root $\alpha$ is an algebraic noninteger direction parameter." Abstract (line 13): "Then $\alpha$ is an algebraic noninteger direction parameter, and $\chi(\Gamma_\alpha)=4$."

```lean
theorem Davidson.not_isIntegral (α : ℂ) (hα : Polynomial.aeval α Poly.f = 0) : ¬ IsIntegral ℤ α
theorem Davidson.isAlgebraic_of_root (α : ℂ) (hα : Polynomial.aeval α Poly.f = 0) : IsAlgebraic ℚ α
theorem Davidson.root_counterexample (α : ℂ) (hα : aeval α Poly.f = 0) :
    ‖α‖ = 1 ∧ IsAlgebraic ℚ α ∧ ¬ IsIntegral ℤ α ∧ 4 ≤ (Gamma α).chromaticNumber
theorem Davidson.exists_root_f : ∃ α : ℂ, aeval α Poly.f = 0
```
Differences:
- The paper derives "not an algebraic integer" from irreducibility of f over ℚ plus "f is not monic". Lean does **not** use (or prove) irreducibility of f. The proof: if α were integral, so would be conj α = α⁻¹ (‖α‖ = 1, `roots_on_circle`), hence y = α + α⁻¹, a root of F (`trace_identity`). But no root of F is integral over ℤ (`NonInteger.F_root_not_integral`): the monic minimal polynomial g of y divides F in ℤ[X]; F mod 3 is irreducible over 𝔽₃ (`NonInteger.P_irreducible`, for the monic associate P = X^6+X^5+2X^4+2X^3+2 = 2·(F mod 3)), so deg g = 6 and F = 2g, contradicting F(0) = 1.
- Irreducibility of P over ZMod 3 is checked with `Monic.irreducible_iff_natDegree'`: a monic factor of degree 1, 2 or 3 is excluded by comparing coefficients and a kernel `decide` over the 3^6 coefficient tuples per degree.
- "χ(Γ_α) = 4" is stated only as `4 ≤ χ(Γ_α)` (the upper bound [D, Thm 4.1] is not formalized; not needed for the refutation).
- Irreducibility of f over ℚ, "primitive" and "no root is a root of unity" remain unformalized; they are not needed.
